## 1. Overview & Scope

This document specifies the Quality Assurance (QA), validation checks, and operational criteria governing the **Semantic Knowledge Graph Ingestion Pipeline**. It ensures that document extraction, Gemini API structuring, OpenCypher script generation, and ArcadeDB multi-model execution operate with high fidelity, zero token waste, and complete schema compatibility.

---

## 2. Apps Script Ingestion QA (`Code.gs`)

### Validation Checklist
- [ ] **Secret Isolation**: Confirm that `GEMINI_API_KEY` is retrieved from `PropertiesService.getScriptProperties()` and never committed to source files.
- [ ] **Zero-Token Pre-Flight Screening**: Verify `isAlreadyIngested(file)` checks `file.getDescription()` for `"schema_v": 1` or `"kg_ingested": true`. Files previously processed must be skipped immediately without invoking Gemini API calls.
- [ ] **Multimodal PDF Handling**: Ensure that binary PDF files are **never** passed to `getDataAsString()`. Ensure they are base64-encoded via `Utilities.base64Encode` and provided through multimodal `inlineData` with `mimeType: "application/pdf"`.
- [ ] **OpenCypher Idempotency (`MERGE`)**:
  - Verify that entity vertices use `MERGE` statements:
    ```cypher
    MERGE (var:Type {name: '...'})
    ```
  - Verify that relationships use `MATCH ... MERGE` statements:
    ```cypher
    MATCH (src:SourceType {name: '...'}), (tgt:TargetType {name: '...'})
    MERGE (src)-[:REL_TYPE]->(tgt);
    ```
  - Confirm that raw `CREATE` statements are **forbidden** to prevent unique index collisions on `(name) UNIQUE` in ArcadeDB.
- [ ] **Literal Sanitization**: Ensure character single-quotes (`'`), backslashes (`\`), and newlines are sanitized so that strings like `O'Reilly Hall` become `O\'Reilly Hall`.
- [ ] **Description Metadata Tagging**: After a seed file is written to `assets/seeds/`, verify that `file.setDescription()` is updated with:
  ```json
  {"schema_v": 1, "kg_ingested": true, "entities_count": N, "relationships_count": M, "seed_file": "03_ingested_...cypher", "updated_at": "..."}
  ```

## 3. Schema & ArcadeDB Database QA (`assets/schemas/01_schema.sql`)

### Validation Checklist
- [ ] **Multi-Model Compliance**: Confirm `01_schema.sql` defines all 5 data models:
  1. **Graph Model**: `CREATE VERTEX TYPE Character`, `Location`, `Faction`; `CREATE EDGE TYPE LOCATED_IN`, `ALLIED_WITH`, `FEATURED_IN`.
  2. **Document Model**: `CREATE DOCUMENT TYPE CampaignSetting`.
  3. **Vector Model**: `CREATE PROPERTY DocumentChunk.embedding VECTOR OF FLOAT` with `FULLTEXT ENGINE HNSW`.
  4. **Key-Value Store**: `CREATE DOCUMENT TYPE KeyValueStore` with `UNIQUE` indexing.
  5. **Time-Series / Full-Text**: `CREATE PROPERTY GameEvent.timestamp DATETIME` with `FULLTEXT ENGINE LUCENE`.
- [ ] **Unique Constraints**: Ensure `CREATE INDEX ON Character (name) UNIQUE` matches the entity normalization logic in `generateCypherSeed()`.
- [ ] **Migration Runner Verification**: Run `python3 scripts/db_runner.py` to ensure all `.sql` and `.cypher` files parse cleanly and return exit code `0`.

---

## 4. Retrieval & HybridRAG QA (`scripts/query_engine.py`)

### Validation Checklist
- [ ] **Two-Stage Execution**: Confirm search queries first perform Stage 1 HNSW vector search to locate top-K text chunks, then extract entity anchors and perform Stage 2 multi-hop graph traversal.
- [ ] **Source Grounding**: Ensure every response generated by Gemini Spark provides explicit source citations (document name + chunk ID) linking back to original Google Drive documents.
